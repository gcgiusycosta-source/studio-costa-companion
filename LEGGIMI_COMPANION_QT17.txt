Companion già usata, conservando origine e percorso per mantenere i dati locali.

Accettare l'aggiornamento dell'app quando viene proposto; non cancellare i dati

Dal desktop: autorizzare i singoli fascicoli nella scheda pratica, quindi
Plugin > Esporta aggiornamento Companion .scmobile. Importarlo nella Companion.
I nuovi SCM0/SCMR0 NON chiedono password e NON SONO CIFRATI: chi possiede il file
può leggerlo. Il checksum verifica corruzioni accidentali, non l'autenticità.
Le modifiche rientrano nel desktop mediante importa risposte .scmr con revisione
esplicita. Non esiste una sincronizzazione automatica in rete.

La Companion 20.10 NON richiede password per gli accessi abituali, per importare
nuovi .scmobile SCM0, per esportare .scmr SCMR0 né per backup .scl SCL0.
Il Vault locale conserva cifratura AES-256-GCM con chiave non estraibile memorizzata
nel browser del dispositivo. Non è più presente il blocco per inattività.
ATTENZIONE: chi accede al browser/dispositivo accede anche ai dati.
La prima apertura di un archivio locale già cifrato con Vault V1 chiede UNA
SOLA VOLTA la vecchia password per migrare tutti i dati senza cancellazioni.
Senza la vecchia password non è possibile recuperare i dati già cifrati.
I vecchi file SCM1 e SCL1 cifrati non sono importabili senza password: rigenerare
il .scmobile dal desktop e il .scl dalla precedente Companion, se necessario.
I nuovi backup .scl SCL0 NON SONO CIFRATI: trattarli come dati riservati.
La password eventualmente prevista dal gestionale DESKTOP non viene modificata.
Il calcolatore mobile storico resta distinto dal nuovo riparto desktop in terzi.
